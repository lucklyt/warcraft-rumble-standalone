# 魔兽大作战 · 真3D本地单机版 (`warcraft-rumble-standalone`)

> **在线直玩（GitHub Pages）**：https://lucklyt.github.io/warcraft-rumble-standalone/

零外网依赖、100% 本地运行的《魔兽大作战》WebGL 真 3D 单机版，完整还原终局首领 **【奥妮克希亚的巢穴 (Onyxia's Lair)】** 原版 `missiondata_onyxia_v1` `56×114` 3D 熔岩洞穴沙盘、3D 棋子手办、真实道路道岔网络、原版 `CombatHUD` 战斗界面与全量 93 位官方棋子配队工坊。

## 快速启动

### 方式一：双击一键启动（macOS）
直接双击根目录的 [`start-game.command`](./start-game.command)，脚本会自动构建（若尚未生成 `dist/`）并启动本地服务器，同时在默认浏览器中打开游戏界面。

### 方式二：命令行启动
```bash
# 运行本地静态服务（默认 http://127.0.0.1:4173/）
npm run serve

# 开发热更新模式
npm run dev

# 构建生产包 (dist/)
npm run build

# 发布到 GitHub Pages (gh-pages 分支)
npm run deploy

# 运行全部测试（93 棋子数值、56×114 奥妮克希亚战斗引擎、3D .glb 与 HUD 完整性校验）
npm test
```

## 核心特色与操作指南

- **真 3D 沙盘与原版美术资产**：
  - **熔岩洞穴场景**：直接提取 `mission_onyxia.bundle` 地形石板、发光熔岩岩壁、4 座不可通行熔岩岩岛与尖刺群岩，配合实时熔岩着色器与火星粒子。
  - **3D 棋子手办**：全 81 款官方可收集棋子 + 7 大阵营底座 + 奥妮克希亚、奥妮克希亚守卫、狗头人矿工、龙蛋、雏龙、联盟/部落要塞、哨塔、金矿与宝箱全部以 WebGL `.glb` 实时渲染，并带空降砸地、桌面弹跳行军、近战/施法前冲与异常状态着色。
  - **战前 3D 转盘工坊**：大厅内置可鼠标拖动 360° 旋转的 3D 棋子手办展台，悬停任意槽位即可实时切换检视模型（支持预览奥妮克希亚与萨尔预设等全部 93 棋子）。
- **操作方式**：
  - **部署棋子**：点击底部手牌（或按键盘 `1`–`4`）后地面会高亮显示原版 `Player Deploy 1/2/3` 及已占塔的蓝色部署网格，点击或从手牌直接拖拽至战场即可空降参战；`Esc` 取消选牌，`Space` 暂停/继续。
  - **战区视角控制**：未选牌时上下拖拽 3D 战场、滚动鼠标滚轮、按 `W`/`S` 或 `↑`/`↓` 键，或者直接点击/拖动右侧 **战术小地图**，均可自由切换基地（`z=0`）至奥妮克希亚王座（`z=78.5`）的视角。
  - **交互式 3D 道岔**：未选牌时点击战场地面旋转的黄色 3D 道岔箭头即可实时改变部队行进分支。
  - **辅助功能**：支持 **AI 托管**（开启/关闭战术 AI 自动接管，仍可随时手动介入）、`1x / 1.5x / 2x` 倍速与重开。

## 已还原奥妮克希亚机制 (`missiondata_onyxia_v1`)

- **真实 `56×114` 拓扑与三塔分布**：
  - 联盟主基地 `(0, 0)` 对应三条首发路径；`Tower 1 (-2, 25)` 位于 47m 清场半径之外（转阶段时**保留**），`Tower 2 (-12, 44)` 与 `Tower 3 (12, 50)` 位于 47m 清场半径之内（`70%` / `40%` 转阶段会被烈焰摧毁并重置回奥妮克希亚控制）。
- **奥妮克希亚三阶段机制**：
  - `P1 (100%–70%)`：12 码 180° 半场火焰吐息（2.5s 间隔），5:40 起每 90 秒在真实 16 个孵化巢坐标中刷出龙蛋（30s 未清除将破壳孵化毒龙）。
  - `P2 (70%–40%)`：净化负面状态 + 47m 半径烈焰清场与击退 + 激活【元素抗性】+ 每 50s 在塌方点召唤守卫土元素。
  - `P3 (40%–0%)`：二次 47m 清场并夺回北侧双塔 + 【护甲 + 抗性】双抗并存 + 每 80s 从北侧双洞口召唤精英【奥妮克希亚守卫】。
