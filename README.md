# 魔兽大作战 · 本地单机版 (`warcraft-rumble-standalone`)

> **在线直玩（GitHub Pages）**：https://lucklyt.github.io/warcraft-rumble-standalone/

零外网依赖、100% 本地运行的《魔兽大作战》单机版垂直切片工程，首期完整还原终局首领关卡 **【奥妮克希亚的巢穴 (Onyxia's Lair)】** 与全量 93 位官方棋子配队工坊。

---

## 快速启动

### 方式一：双击一键启动（macOS）
直接双击根目录的 [`start-game.command`](./start-game.command)，脚本会自动构建（若尚未生成 `dist/`）并启动本地服务器，同时在默认浏览器中打开游戏界面。

### 方式二：命令行启动
```bash
# 运行本地静态服务（默认 http://127.0.0.1:4173/）
npm run serve

# 开发热更新模式
npm run dev

# 构建生产包 (dist/)
npm run build

# 发布到 GitHub Pages (gh-pages 分支)
npm run deploy

# 运行自动化单元与无头战斗测试
npm test
```

## 操作说明

- **战前整备大厅**：
  - 预设切换：内置用户默认 **萨尔部落元素强力队** 与 4 套官方 S 级奥妮克希亚推荐阵容。
  - 全图鉴配队：点击主将或 6 个士兵槽位可更换全部 93 位棋子与 3 个天赋（严格按 `codeIndex` 匹配）；点击槽位下方 `◀` / `▶` 可调序。
  - 分享码导入导出：支持直接粘贴或复制官方 `rumblo:` Base64 Protobuf 分享码。
  - 难度选择：提供 **练习模式 (+2 级)**、**标准同级 (1.00x)** 与 **终局越级 (Boss +2 级)**。
- **战斗界面操作**：
  - **部署棋子**：点击底部手牌（或按键盘 `1`–`4`）选中后点击战场高亮合法区部署，也可直接从手牌按住拖拽至战场松手。`Esc` 取消选牌，`Space` 暂停/继续。
  - **变向道岔**：未选牌时点击战场上的蓝色 `◀` / `▶` 道岔图标即可实时切换后续部队行进路线。
  - **辅助功能**：顶部支持 `🤖 托管`（开启/关闭战术 AI 托管，仍可随时手动介入）、`1x / 1.5x / 2x` 倍速与重开。

## 已还原核心机制

- **奥妮克希亚三阶段机制**：
  - `P1 (100%–70%)`：12 码 180° 半场火焰吐息（2.5s 间隔），5:40 起每 90 秒在左右巢穴刷出黑龙蛋（30s 未清除将破壳孵化毒龙）。
  - `P2 (70%–40%)`：净化负面状态 + 烈焰清场线（`y = 26.5` 以上单位击杀、以下单位按重量击退、双顶塔重置但**中路要塞塔保留**）+ 激活【元素抗性】+ 每 50s 塌方召唤 3 只攻城土元素。
  - `P3 (40%–0%)`：二次清场夺顶塔 + 【护甲 + 抗性】双抗并存 + 每 80s 从左右洞口召唤精英【奥妮克希亚守卫】。
- **属性克制与主流技能**：护甲物理减半、抗性元素减半、攻城双倍、飞行免疫近战与轰炸、无限叠层剧毒，以及萨尔图腾掌握/野性狼魂/闪电链、达基萨斯多彩龙鳞、阿尔萨斯冰霜光环/死亡之握/炼狱、拉格纳罗斯附体要塞与冲击波、全 12 张法术及重点士兵天赋。
